# NLP_sentiment-analysis
Reproduces Liao (2024) binary sentiment classification on SST-2, evaluates transfer to IMDB, and compares TF-IDF baselines (KNN, Random Forest, Naive Bayes, Logistic Regression) with an MLP and a fine-tuned DistilBERT. Includes a Django and Next.js interface for training, live prediction, McNemar–Holm tests, and feature ablations.
